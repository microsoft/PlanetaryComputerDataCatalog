name: link-example-notebook
description: Use instructions when linking Jupyter notebooks to the data catalog.
---

Jupyter notebooks are in the https://github.com/microsoft/PlanetaryComputerExamples
github repository. When notebooks are added, we need to add them to the appropriate
section in the data catalog.

Ask the user for the PR number or link where the new notebook has been added. The
files to modify are:

1. etl/config/codefiles_urls.txt
2. src/config/datasets.yml
